# juliusernst.com

- site.js: all content (the block marked EDIT HERE) and the code. Edit text here.
- style.css: colours, sizes, spacing.
- index.html: the front page. 404.html: shown for addresses that don't exist.
- one folder per work page (territorie/, other-work/ ...), each with the same small index.html.
  New work with a page: add it in site.js, then create <address>/index.html with the
  contents of territorie/index.html. The address is the title in small letters with dashes.
- images/, fonts/: files used by the site. CNAME: the domain.
